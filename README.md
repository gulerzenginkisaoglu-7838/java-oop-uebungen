# Java OOP Übungen

Übungsprojekte im Rahmen der Umschulung zum Fachinformatiker Systemintegration (GFN GmbH).

Diese Sammlung zeigt die Umsetzung grundlegender Konzepte der objektorientierten Programmierung in Java: Interfaces, Vererbung, Polymorphie und Kapselung.

## Projekte

### 1. Bezahlsystem
Implementierung eines einfachen Zahlungssystems mit dem Interface-Konzept.

- `Zahlungsmethode.java` – definiert die gemeinsame Schnittstelle für Zahlungsarten
- `Kreditkarte.java` – Implementierung der Zahlungsmethode per Kreditkarte
- `PayPal.java` – Implementierung der Zahlungsmethode per PayPal
- `Hauptprogramm.java` – Demonstration der polymorphen Verwendung beider Zahlungsarten

**Gezeigte Konzepte:** Interface-Implementierung, Polymorphie

### 2. PaketInterface
Modellierung geometrischer Objekte über ein gemeinsames Interface.

- `IObjekt2D.java` – Interface für 2D-Objekte (z. B. Flächen- und Umfangsberechnung)
- `Kreis.java` – Implementierung für Kreise
- `Rechteck.java` – Implementierung für Rechtecke
- `Hauptprogramm.java` – Demonstration der Verwendung verschiedener 2D-Objekte

**Gezeigte Konzepte:** Interface-Implementierung, Kapselung, Polymorphie

*Hinweis: Die Dateien in diesem Ordner wurden mit Unterstützung von Claude auf Basis der ursprünglichen Aufgabenstellung rekonstruiert und vervollständigt.*
